Recall Sloth

Nobody reads recall notices. Paste what you've bought and Gemma, running here in your browser, checks every item against every U.S. consumer product recall since 2016. What you paste never leaves this page.

Model

How it decides: a recall is only a candidate when it names the same brand and the same kind of thing. If the notice's model number is in what you pasted, it says recalled. If the notice names a different model than yours, it says not this one. Otherwise Gemma reads the notice next to your item, and anything it isn't sure about becomes check the label, with the notice's own words on where to look. Code and evaluation.
